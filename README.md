# 🍽️ FOODWARS

> **The ultimate comfort food tournament. Build your bracket, settle impossible food debates, and discover the food personality behind every choice.**

Everyone has argued about food.

**Pizza or Burger?**

**Brownie or Ice Cream?**

**Fries or Onion Rings?**

FOODWARS transforms those everyday debates into an interactive tournament where your favorite comfort foods battle until only one champion remains.

More than just choosing what to eat, every decision shapes your unique **Food DNA**, revealing your taste personality, battle history, and ultimate comfort food champion.

## ✨ Philosophy

Choosing food is usually a repetitive experience.

Open a delivery app.

Scroll endlessly.

Still order the same thing.

FOODWARS asks a different question.

> **What if deciding what to eat felt as exciting as winning a championship?**

Instead of endless menus, every meal begins with a battle where only one food survives.

---

## 💡 The Problem

Food recommendation apps focus on showing more options.

More restaurants.

More filters.

More scrolling.

Ironically, having more choices often makes deciding even harder.

Most platforms answer **"What's available?"**

FOODWARS answers **"What do you actually love?"**

---

## 🚀 The Solution

FOODWARS turns food discovery into a tournament.

Players choose a comfort-food category before entering a randomized knockout bracket where dishes compete head-to-head.

Every victory influences the final outcome.

By the end of the tournament, players don't just discover a winning dish—they unlock a personalized **Food DNA** report complete with personality insights, battle statistics, rankings, and tournament highlights.

Instead of recommending food...

FOODWARS lets players earn their champion.

---

## 🌟 Features

### 🏆 Interactive Tournament Brackets

Battle comfort foods in randomized 2, 4, 8, or 16-player knockout tournaments.

### 🍕 Five Comfort Food Divisions

Explore carefully curated categories including cheesy, spicy, sweet, warm, and crispy favorites.

### ⚔️ Animated Food Battles

Vote using clicks or keyboard shortcuts while enjoying smooth transitions and dynamic matchups.

### 🧬 Food DNA Report

Unlock a personalized analysis revealing your taste profile, personality, rankings, and tournament statistics.

### 🎉 Championship Celebration

Celebrate your winner with sound effects, confetti, and an editorial-style results screen.

### 📱 Responsive Experience

Designed to feel equally immersive across desktop, tablet, and mobile devices.

## ⚡ Technical Highlights

- Interactive tournament engine with randomized bracket generation.
- Component-driven React architecture for reusable game screens.
- Dynamic Food DNA calculations based on player decisions.
- Motion-powered animations for immersive gameplay.
- Responsive layouts optimized for desktop and mobile.
- Sound effects and celebration mechanics using the Web Audio API.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Konarksharma13/FOODWARS.git
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Visit:

```text
http://localhost:3000
```

## 📚 Lessons Learned

FOODWARS challenged me to think beyond building another frontend application.

It taught me how game mechanics, interaction design, and visual feedback can make ordinary experiences feel engaging.

While building the tournament engine, I strengthened my understanding of React state management, reusable component architecture, animation sequencing, and responsive UI design.

More importantly, it reinforced that great frontend experiences aren't just about how an application looks—they're about making users want to interact with it again.
